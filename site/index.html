NAME

dotfiles.bostonaholic.dev - there's no place like ~

SYNOPSIS

Click to copy.

curl dotfiles.bostonaholic.dev | bash -s -- [options]

DESCRIPTION

Sets up a fresh Mac with Matthew Boston's dotfiles. Clones bostonaholic/dotfiles into ~/dotfiles, or updates it if it is already there, then runs install.sh: symlinks, Homebrew packages, npm, pipx and uv tools, Claude Code plugins, and setup scripts.

Installs the Xcode Command Line Tools first if they are missing. Safe to run again; install.sh only changes what is out of date.

OPTIONS

--minimal
Dotfiles only. Skips packages, plugins, and scripts.
--no-apps
Skips Homebrew packages.
--no-plugins
Skips Claude Code plugins.
--dir path
Clones into path instead of ~/dotfiles.
-n, --dry-run
Clones, then previews install.sh without changing anything.
-y, --yes
Answers yes to every install.sh prompt.

ENVIRONMENT

DOTFILES_REPO
Repository to clone. Default: https://github.com/bostonaholic/dotfiles.git
DOTFILES_DIR
Where to clone it. Default: ~/dotfiles
DOTFILES_BRANCH
Branch to check out. Default: main

EXAMPLES

Preview everything without changing the machine:
curl dotfiles.bostonaholic.dev | bash -s -- --dry-run
Link the dotfiles and nothing else:
curl dotfiles.bostonaholic.dev | bash -s -- --minimal
